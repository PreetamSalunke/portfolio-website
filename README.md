
# Personal Portfolio Website

A responsive personal portfolio website created using HTML5 and CSS3.

## About the Project

This website showcases my profile, technical skills,
education, certifications, and web development projects.

## Features

- Home page with introduction
- About page with education and certifications
- Skills section
- Featured projects section
- Projects page with project details
- Contact page with a basic HTML form
- Responsive design for desktop and mobile
- Navigation links between pages

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Media Queries

## Project Structure

- index.html - Home page
- about.html - About page
- projects.html - Projects page
- contact.html - Contact page
- css/style.css - Website styling
- assets/ - Images and other assets

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in a web browser.

## Contact Form

The contact form includes Name, Email, and Message fields.
It uses basic HTML validation.
Backend message submission is not implemented.
